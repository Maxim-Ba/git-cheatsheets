# Git: шпаргалки и настройка машин

Шпаргалки для того, чтобы на **каждой** вашей машине git вёл себя одинаково и подписывал
коммиты одним именем и одной почтой. Написано по итогам разбора реальных проблем:
четыре разные подписи автора в одной истории, лишние merge-коммиты от `git pull`,
коммит «+10000/−10000» из-за CRLF/LF и недоступный по SSH git-хостинг.

## Порядок работы

1. **Решите, какая личность будет единственной** (раздел «Решение» в `01-…`). Это единственное решение, которое за вас принять нельзя.
2. На каждой машине запустите `scripts/setup-machine.*` с этими именем и почтой (сначала с `-DryRun` / `--dry-run`).
3. Один раз на каждый репозиторий положите `.gitattributes` и сделайте отдельный коммит нормализации (см. `03-…`).
4. Настройте SSH на каждой машине (`04-…`).

## Типичные проблемы, которые разбирают шпаргалки

- В истории несколько вариантов подписи автора (разный порядок имени, личная и рабочая почта,
  noreply-почта веб-интерфейса).
- `pull.rebase` и `core.autocrlf` не заданы.
- `.gitattributes` перечисляет только часть расширений и не содержит `* text=auto`, поэтому
  остальные файлы дают шум CRLF/LF.
- SSH к хостингу отвергает все ключи (`Permission denied (publickey)`): ключ не добавлен в аккаунт.
